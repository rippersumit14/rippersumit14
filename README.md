## Current Project

### RepoPulse — GitHub Repository Health Analyzer

RepoPulse is a full-stack application for analyzing the engineering health of public GitHub repositories.

The platform is being designed to evaluate repository activity, development practices, documentation, testing, CI/CD adoption, issue and pull-request activity, and other repository signals to produce an explainable repository health score.

The backend is being developed with an emphasis on API design, separation of concerns, asynchronous external API communication, relational data modeling, maintainability, and production-oriented engineering practices.

**Technology:** Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic, HTTPX, React, TypeScript

**Status:** Active development
